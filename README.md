# 🎓 e-JDU LMS Autonomous AI Agent & Web Dashboard

Python, Playwright va Gemini 2.5/3.8 Flash AI asosida ishlovchi avtonom robot va boshqaruv veb-sayti.

## ✨ Imkoniyatlar
- 🖥️ **Zamonaviy Veb Interfeys**: Barcha funksiyalar brauzer orqali boshqariladi.
- 👥 **Multi-Profil Tizimi**: Istalgancha yangi talaba qo'shish, tahrirlash va darslarini yakunlash.
- 🎯 **Dinamik AI Buyruqlari**: Talabaning ehtiyojiga qarab maxsus topshiriqlar yuklash.
- 📺 **Jonli Ekran (Live Screen Viewport)**: Playwright brauzerining ekranini real vaqtda ko'rib turish.
- 📜 **Konsol Loglari**: Rangli bildirishnomalar, qaysi dars o'rganilayotgani va test javoblari.
- ⚡ **Tezlik va Vaqtni Boshqarish**: Videolarni tabiiy 1.0x yoki 1.25x tezlikda ko'rish, slaydlar kutish vaqtini belgilash.
- 🔄 **24/7 Avtonom Sikl**: Barcha darslar tugasa, tizim avtomatik kutish rejimiga o'tib, yangi darslarni tekshirib turadi.

## 🚀 Ishga tushirish

Lokal kompyuterda:
```bash
chmod +x start.sh
./start.sh
```
